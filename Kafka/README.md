# Kafka 

## Here are some open-source and free desktop Kafka GUI clients/admin apps for Windows that are not web-based:

### 1. **Kafka Tool**
   - **Website**: [Kafka Tool](https://www.kafkatool.com/)
   - **Features**: Kafka Tool is a popular GUI application for managing and using Apache Kafka clusters. It offers topic management, consumer group monitoring, message browsing, and more. The community edition is free for personal use.
   - **Platform**: Windows, macOS, Linux

### 2. **Offset Explorer (formerly Kafka Tool Community Edition)**
   - **Website**: [Offset Explorer](https://www.kafkatool.com/download.html)
   - **Features**: Offset Explorer is the open-source, community edition of Kafka Tool. It provides basic features such as browsing topics, sending messages, and monitoring consumer groups.
   - **Platform**: Windows, macOS, Linux

### 3. **kafdrop (Desktop Version)**
   - **Repository**: [kafdrop](https://github.com/obsidiandynamics/kafdrop)
   - **Features**: Although Kafdrop is primarily a web-based tool, there is a desktop wrapper version that allows it to be run as a standalone application on your desktop. It provides a nice UI for exploring topics, consumer groups, and messages.
   - **Platform**: Java-based, so it can run on Windows, macOS, and Linux

### 4. **AKHQ (Desktop Version)**
   - **Repository**: [AKHQ](https://github.com/tchiotludo/akhq)
   - **Features**: Like Kafdrop, AKHQ is typically web-based, but can be packaged as a desktop app using Electron or similar tools. It offers extensive Kafka management features, including topic exploration, consumer group monitoring, schema registry support, and more.
   - **Platform**: Java-based, so it can run on Windows, macOS, and Linux

### 5. **kafkatools (Python-based)**
   - **Repository**: [kafkatools](https://github.com/simplesteph/kafka-tools)
   - **Features**: A simple, Python-based command-line and GUI tool for managing Kafka. It's lightweight and allows for basic Kafka cluster operations.
   - **Platform**: Windows (requires Python)

### 6. **YAKC (Yet Another Kafka Client)**
   - **Repository**: [YAKC](https://github.com/cosminseceleanu/yakc)
   - **Features**: A simple and lightweight Kafka client that supports basic Kafka operations like producing, consuming, and browsing messages.
   - **Platform**: Java-based, so it can run on Windows, macOS, and Linux

These tools provide various levels of functionality and should help you manage your Kafka clusters effectively from a desktop environment on Windows.
